# Iron Path design direction

This folder contains visual references and local assets for the new Ropejumping design direction.

## Style

Brutal outdoor rope community / dark expedition UI.

The interface should feel like:
- ropejumping community hub;
- mountain expedition dashboard;
- dark outdoor / rusty metal / grunge environment;
- strong photo-based layout;
- rough but readable UI.

## Important rules

- Keep the design dark.
- Do not create a separate light theme.
- Use rusty orange accents.
- Use atmospheric images and grunge texture carefully.
- Keep text readable.
- Do not add random external assets.
- Do not add new icon libraries.
- Do not change business logic.
- Do not change Prisma schema or migrations.
